# 🎧 dsh-session-tts · 会话语音朗读

把 **DeepSeek Harness (DSH)** 会话里的回复念出来。

用微软 Edge 的在线神经网络语音——**免 API Key、无需显卡、不落盘模型**，
设置页里点一下就能换音色，还能自动按句判断语气。

| | |
|---|---|
| 引擎 | Microsoft Edge 神经语音（在线） |
| 成本 | **0 元**，不用 Key |
| 依赖 | 纯 JS，**零原生模块** |
| 音色 | 中文**普通话女声** 2 个 |
| 语气 | 5 档预设 + **自动按句判断** |
| 平台 | 桌面 DSH ✅ / Android DSH ✅ 均实测可用 |

---

## ✨ 功能

### 每条回复下面一个 `▶`

点一下念这一条，再点一下停。念的是哪条都行，不用是最新的。

### 输入框下方：整段朗读

```
🔊 朗读本会话   待命   ○ 自动朗读
```

- **朗读本会话** —— 把整段会话的助手回复按顺序念完
- **自动朗读** —— 开着时，每说完一轮自动念出来（只念开启之后的新回复）

### 设置 → 语音朗读

```
音色：[晓伊] [晓晓]
语气：[自然] [温柔] [严肃] [活泼] [低沉]
语速 ────●──── 0.92×
音高 ──●────── −8Hz
[▶ 试听] [⏸ 停止] [✓ 自动朗读]
自动语气
[✓ 开：按句自动判断情绪，分别调整语速音高]
```

**点音色会立刻试听**，选中的会存下来，重启不丢。

## 🎭 自动语气（这个插件的重点）

TTS 模型本身不读情绪——它只照着文字念。所以这个插件自己做了判断层：

**按句切分 → 逐句分类 → 只调整语速 → 拼成一条音频。**

> 自动语气**只改语速，不改音高**。音高始终等于你在设置里设定的基准值，所以音色本身不会被拉变形。

| 语气 | 触发条件 | 语速 |
|---|---|---|
| `low` 低落/迟疑 | 遗憾 / 抱歉 / 出错 / 踩坑 … 或出现 `……` | ×0.90 |
| `lively` 兴奋 | 太好了 / 搞定 / 通过 … 或出现 `！` | ×1.08 |
| `serious` 严肃 | 注意 / 必须 / 警告 / 风险 … | ×0.95 |
| `gentle` 温和 | 谢谢 / 辛苦 / 别担心 / 慢慢来 … | ×0.94 |
| `question` 疑问 | 以 `？` 结尾 | ×1.02 |
| `natural` 自然 | 其余 | ×1.00 |

这些是相对倍数，乘在你设定的语速基准上。

**实测**：一段 67 字的话被切成 5 组、耗时约 2.2 秒、输出 18.3 秒音频。

组件按帧拼接 MP3（剥离各段 ID3 头），校验结果 **761 帧 / 0 字节错位**。

> **边界**：这是"节奏起伏"，不是真的情绪演出。它能做到"这句读快一点、那句读慢一点"，做不到"声音发抖"或"笑出来"。要真情绪得换带情感建模的本地引擎。

## 🧹 文本清洗

念之前会把**不适合朗读的字符**去掉，避免 Edge 把它们读成杂音或奇怪的停顿：

| 类别 | 例子 | 处理 |
|---|---|---|
| 表情符号 | ✅ 🔊 🎉 🎧 | 删除 |
| 箭头 / 几何图形 / 方框绘制 | ▶ → ■ ─ │ | 删除 |
| 带圈数字 / 数字键帽 | ① 1️⃣ | 删除图形部分，保留数字 |
| 商标符号 | ™ © ® | 删除 |
| Markdown 标记 | `**加粗**` `` `代码` `` `# 标题` `- 列表` | 去掉标记，保留文字 |
| 表格 | `\| 项目 \| 值 \|` 与 `---\|` 分隔行 | 去掉竖线和分隔行 |
| 链接 / 图片 | `[文字](url)` `![图](url)` | 保留「文字」，丢弃 URL |

**保留不动**：中文标点（，。！？；：、…—）、英文标点、数字、百分号、正常的中英文字符。

## 📦 安装

### 桌面端 DSH

插件管理器里安装，或命令行：

```sh
dsh plugin --profile desktop add github:jingyunex/dsh-session-tts
```

装完重启 DSH。

### Android（DSHAPP / DSH0.3.0）

在「插件 → 添加插件」里，安装源选**自定义地址**，填：

```
https://github.com/jingyunex/dsh-session-tts
```

依赖 `msedge-tts` 会由 pnpm 自动安装。

> Android 上首次播放需要**先点一下页面**——移动浏览器和 WebView 默认禁止自动播放声音，插件已内置手势解锁。

### ✅ 已验证环境

| 环境 | 结果 |
|---|---|
| DSH 0.2.1-rc.2 + Windows（桌面端） | ✅ 安装、朗读、自动语气全部正常 |
| **DSH 0.3.0（`com.dsh.android`，Android）** | ✅ **通过插件管理器从本仓库安装成功，可正常朗读** |

Android 端已验证的关键点：

- 从 GitHub 地址安装，`msedge-tts` 依赖自动拉取
- 零原生模块，Android 上无编译/加载问题
- WebView 内 MP3 播放正常，手势解锁生效

> 说明：Android 端的 DSH 是把引擎跑在手机本机（`127.0.0.1`），不需要电脑参与，也不涉及局域网穿透。

## 🌐 音色

只有**普通话女声**（`zh-CN`，不含方言区）：

| 音色 | ID |
|---|---|
| 晓伊 | `zh-CN-XiaoyiNeural` |
| 晓晓 | `zh-CN-XiaoxiaoNeural` |

这不是过滤得太狠——**免费的 Edge 朗读通道里，普通话女声就只有这两个**。

想要更多（18 个普通话女声 + 情绪风格），需要付费的 Azure 语音服务；

## ⚙️ 配置

设置存于 `<DSH_HOME>/session-tts.json`：

```json
{
  "edgeVoice": "zh-CN-XiaoyiNeural",
  "rate": 0.92,
  "pitch": -8,
  "autoTone": true,
  "autoRead": false,
  "maxChars": 1500
}
```

## 🔌 HTTP 接口

全部挂在插件私有前缀下，仅本机可访问：

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/dsh-session-tts/settings` | 读设置 |
| POST | `/dsh-session-tts/settings` | 改设置（只改传了的字段） |
| GET | `/dsh-session-tts/voices` | 列可用音色 |
| POST | `/dsh-session-tts/speak` | 合成。`{text}` / `{sessionId, messageId}` |
| GET | `/dsh-session-tts/session-text?sessionId=` | 整段会话的回复，切好段 |
| GET | `/dsh-session-tts/sessions` | 当前载入的会话 |
| GET | `/dsh-session-tts/audio?id=` | 取合成好的音频 |
| GET | `/dsh-session-tts/status` | 诊断信息 |

## ⚠️ 说明与边界

- **需要联网** —— 文本会发往微软的朗读服务，不会经手第三方
- **单次合成约 1.5 秒**，输出 24 kHz 单声道 MP3
- 文本超过 `maxChars` 会被截断（默认 1500 字）
- 手机锁屏/切后台会中断播放（系统限制）
- 历史版本曾内置离线 Kokoro 引擎，2.0.0 起已移除
